# Contributing / Contribuir

Issues and pull requests are welcome. / Se aceptan issues y pull requests.

- Keep the firmware compiling: CI runs `esphome config` and `esphome compile` on every PR.
- Never commit `esphome/secrets.yaml` or real credentials; use `secrets.example.yaml` for placeholders.
- Changes that touch the relay wiring or the safety timer should say how they were tested on the bench.
- Cambios en el cableado del relé o en el temporizador de seguridad: indicá cómo se probaron en banco.
